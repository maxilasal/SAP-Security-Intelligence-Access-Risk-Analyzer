Instalar el certificado (una vez por PC)

{% if net.ca %}

La conexión ya está cifrada. Instalar el certificado sirve para que el navegador reconozca a este servidor y deje de mostrar «La conexión no es privada» (la primera vez, para llegar hasta acá, se elige Configuración avanzada › Continuar).

Cómo hacerlo
  1. Descargar el certificado
  2. Abrir el archivo descargado › Instalar certificado… › Usuario actual › Siguiente › «Colocar todos los certificados en el siguiente almacén» › Examinar… › Entidades de certificación raíz de confianza › Aceptar › Siguiente › Finalizar.
  3. Windows pregunta si confía: la huella (sha1) debe ser {{ net.ca_thumbprint }}. Si coincide, Sí; si no, no lo instale y avise a seguridad.
  4. Cerrar y volver a abrir el navegador.

Para todas las PC a la vez, TI puede distribuirlo por directiva de grupo (GPO): Configuración del equipo › Directivas › Configuración de Windows › Configuración de seguridad › Directivas de clave pública › Entidades de certificación raíz de confianza. Firefox usa su propio almacén: Ajustes › Privacidad y seguridad › Ver certificados › Autoridades › Importar.

El certificado solo es válido para este servidor, su dominio y direcciones privadas: no sirve para suplantar otros sitios. Huella SHA-256: {{ net.ca_fingerprint }}
