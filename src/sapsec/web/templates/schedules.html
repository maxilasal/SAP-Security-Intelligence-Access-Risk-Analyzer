Extracciones programadas

Para que los sistemas se extraigan solos, por ejemplo todas las madrugadas. Se procesan de a uno y al terminar se analizan; a la mañana «Qué corregir primero» ya está actualizado.

1 · Con la aplicación abierta

✓ La aplicación revisa cada minuto y ejecuta lo programado.

2 · Aunque la aplicación esté cerrada

✓ Tarea de Windows instalada: revisa cada 30 minutos.

{% elif is_windows %}

Falta instalar la tarea de Windows (una sola vez). En PowerShell, en la carpeta de la aplicación:

powershell -ExecutionPolicy Bypass -File scripts\instalar_tarea_programada.ps1

{% else %}

Disponible en Windows: scripts\instalar_tarea_programada.ps1.

{% endif %}

Requisitos

El equipo encendido a esa hora (la tarea lo despierta si está suspendido) y el mismo usuario de Windows que guardó las contraseñas de SAP. Si a la hora programada el equipo estaba apagado, se ejecuta al encenderse dentro de las 3 horas siguientes; después se omite para no cargar PRD en horario laboral.
